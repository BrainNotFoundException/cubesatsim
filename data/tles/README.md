# data/tles/

Real TLEs used for SGP4 validation. Save each one as a dated text file, e.g.
`iss_2026-11-03.txt`, so the validation plot can be reproduced later with the
exact same input.

Source: https://celestrak.org (e.g. the "stations" group for the ISS).
Pick a LEO satellite; the ISS is a good first choice because drag matters.
